## 二、学习路径

1. **先建立概念**：读 [网络基础概念](../01-计算机基础/计算机网络/思科网院-网络概念.md)，知道冗余/可扩展性/QoS 各自解决什么、设备有哪几种访问方式。
2. **再动手复现**：打开 Packet Tracer 跟着 [实验笔记](网络工程/Cisco-Packet-Tracer-实验笔记.md) 敲命令，重点看 `show running-config` / `show startup-config` 与 RAM / NVRAM 的区别。
3. **最后过考点**：用 [设备访问控制](网络工程/Cisco-设备访问控制与密码验证.md) 的表格与易错点自测，把密码体系、SSH/Telnet、协议概念串起来。

## 三、串联起来的关键点（均摘自三篇原文）

**设备访问与密码**
- 三条入口对应三套密码：`line console 0` → Console 密码、`line vty 0 15` → VTY 密码、`enable secret` → 特权模式密码；`login` 不配则密码不生效，`enable secret` 优先于 `enable password`。
- SSH(22) 密文 / Telnet(23) 明文；带内管理走 SSH/Telnet，带外管理走 Console 或 AUX。
- PuTTY / SecureCRT / Xshell 只是终端仿真软件，不要和协议绑定。

**实验操作**
- `Shift + P` 物理模式、`Shift + L` 逻辑模式；`copy running-config startup-config` 保存配置。
- 直通线连不同类设备、交叉线连同类设备；UTP 靠线对扭绞抵消串扰，Cat5e 1 Gbps、Cat6/7 10 Gbps、Cat8 40 Gbps。
- MAC 帧在每段链路上会改写目的 MAC，跨网必须配默认网关；交换机有存储转发与直通转发两种方式。

**协议与概念**
- 网络协议定义语法（格式）、语义（含义）、时序（顺序与速率）；选择题里 `all` / `only` / `hardware` 多为陷阱。
- 物理层 `1 Byte = 8 bits`，速率单位 bit/s；冗余靠冗余接口与分组交换。
