# DHCP动态主机配置协议
作用![Pasted image 20261111192542](../../../../assets/images/根目录/Pasted%20image%2020261111192542.png)

DHCP使用UDP的运输层协议
服务器段的端口号是67  客户端的进程端口号68



新接入的主机发送DHCP DISCOVER发现报文（源IP 0.0.0.0 目的ip 255.255.255.255 报文中有主机的MAC地址）

服务器接收到后 查表：是否有该MAC地址的ip配置，如果有就返回该配置，没有就安装默认的规则配置  发送OFERR报文（目的ip是255.255.255.255 源地址是DHCP服务器）

客户机根据OFFER中的事务ID是否匹配来接受

![Pasted image 20261111194750](../../../../assets/images/根目录/Pasted%20image%2020261111194750.png)


分配IP时，DHCP要发送ARP报文，确保所选的IP没有冲突

![Pasted image 20261112190048](../../../../assets/images/根目录/Pasted%20image%2020261112190048.png)
DHCP客户端接受后发送DHCP REQUEST报文，用于选择一个DHCP作为自己的服务器，等到收到确认报文后，在使用租用的IP 
源IP地址：0.0.0.0 目的地址：255.255.255.255

在0.5倍租用期时，再发送一个DHCP请求报文
