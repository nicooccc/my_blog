## 期末重点（浮点数的表示）
    在数据中全E为全 1 代表
    {
        1，M全为0，根据S判断+- 无穷
        2，M不为全0，为非数值NAN
    }
    所以最大的正数和最小的负数E为全一 —— 1
### fp32(1S 8E 23M)

    移码为127（7FH）
    V = (-1)^s * 1.M * 2^(E - 7FH)   ( 1<=E <= FEH（254）)
    V = (-1)^s * 0.M * 2^( -126 )    (E 为00H)

### fp16(1S 5E 10M)
    移码为15（0FH）
    V = (-1)^s * 1.M * 2^(E - 0FH)   ( 1<=E <= 0EH)
    V = (-1)^s * 0.M * 2^( -14 )    (E 为00H)

### 总结
    只要E为8为移码就是7FH，5位0FH

#### 小字长转大字长  
- 原数据位无符号类型，进行0拓展  
```c
    unsigned char uc = 254;     1111 1110
    short s;                    
    s = (short) uc;             0000 0000 1111 1110 //用补码解释
    s = 254
```
- 原数据为有符号类型，进行符号拓展  

```c
    char c = -128;     1000 0000
    short s;                    
    s = (short) c;             1111 1111 1000 0000 //用符号位补，用补码解释
    s = -128
```

## ISA(指令集体系结构)
    可执行的指令的集合，包括指令格式、操作种类以及每种操作对应的操作数的相应规定；

    指令获取操作数的方式，即寻址方式；  
    指令执行过程的控制方式，包括程序计数器、条件码定义等

## 目标文件
![alt text](image-32.png)
    二、 可重定向文件（Relocatable Object File）
常见后缀：Linux下是 .o，Windows下是 .obj。  
生成者：汇编器（Assembler）。  
核心特点：  
地址未确定（从0开始）：它内部的代码和数据都假定自己是从地址 0 开始的。   
包含符号表和重定位表：里面记录了“我这里有段代码引用了外部函数   printf，但我不知道它在哪，请链接器告诉我”。  
不能直接运行：因为它还有“断头路”（未解析的外部符号），操作系统无法直接加载它执行。  
作用：作为链接器（Linker）的输入。  
三、 可执行文件（Executable File）  
常见后缀：Linux下通常是 a.out 或没有后缀，Windows下是 .exe。  
生成者：链接器（Linker）。  
核心特点：  
地址已确定：链接器把所有的 .o 文件和库文件拼装在一起，解决了所有的“断头路”（符号解析），并且根据操作系统的内存布局，给代码和数据分配了具体的虚拟内存地址（重定位）。  
包含程序入口点：比如在ELF格式中，有明确的 Entry point 地址，告诉CPU第一条指令从哪里开始执行。  
可以直接运行：操作系统（Loader）可以直接把它加载到内存中，跳转到入口点开始执行。  
作用：作为操作系统加载器的输入。

### 保护模式寻址

![alt text](image-37.png)
    结合图中的公式 LA = (SR) + (B) + (I)×S + A，假设我们在 C 语言中要访问一个二维数组或者结构体数组：  
    场景：访问 Arr[i].age（假设 Arr 是一个结构体数组）  
    (SR)：段寄存器，确定整个程序数据段在哪。  
    (B)：基址寄存器，指向数组 Arr 的第一个元素的首地址（起点）。  
    (I)：变址寄存器，存放循环变量 i（比如第 3 个元素）。    
    S：比例系数，结构体 Arr 的大小（比如每个结构体占 8 字节，S=8）。  
    A：位移量，指令中给定的固定偏移（比如 age 在结构体内部偏移 4 字节）

### 通用数据传送指令  


#### mov 一般传输指令
    movb(8位),movw(16),movl(32)  
    可以用来截断，从多位到低位  
#### movs 带符号的拓展传输指令  (带符号整形)(低位到多位)
    movsbw 将一个字节进行符号拓展并且送到一个字节中
#### MOVZ
    零扩展传送指令，将短的源数据高位零扩展后传送到目的地址，适用于无符号整形数据
    movzwl将1个字的高位进行零扩展后送到1个双字地址

#### XCHG 
    数据交换指令，将两个寄存器内容交换  
    xchgb表示字节交换  
#### PUSH（小端
    先执行R[sp]←R[sp]-2或R[sp]←R[sp]-4，然后将一个字或双字从指定寄存器送到SP或ESP指示的栈单元中  
    pushl表示双字压栈，pushw表示字压栈  
#### POP（小端  
    先将1个字或双字从SP或ESP指示的栈单元送到指定寄存器，然后执行R[sp]←R[sp]+2或R[sp]←R[sp]+4  
    popl表示双字出栈，popw表示字出栈

    看懂乘法指令 mulb 和 imulb  
    在 x86 的 8位乘法中，有一个隐藏规则（隐含操作数）：  
    被乘数默认放在 AL 里。  
    乘数写在指令里（这里是 BL）。  
    8位 × 8位 = 最大16位，所以结果固定存放在 AX 里（高8位 AH，低8位 AL）。  
    根据几位，去找隐藏操作数  
    如果是b就找al,乘数被写在操作数里   
    R[eax]=000001B6H，R[ebx]=00FF0110H  
    mulw %bx  
    含义： DX - AX <- R[ax] * R[bx]  
    R[eax]=080480B4H，R[ebx]=00000011H，M[080480F8H]=000000B0H，执行指令 imull $-16 //立即数，(%eax,%ebx,4)//储存器地址M[]，%eax//寄存器  
    将储存器中的数值 * 立即数 存入寄存器中，储存器中数值不变  
    基质加变质偏移  
    储存器地址  080480B4 + 0000 0011 * 4     
    截断的符号根据目的的字节长度   
    LEAL 的作用是：计算源操作数的内存地址（有效地址），并将这个地址（而不是地址里的内容）直接存入目的寄存器。    
    addl (%eax), %edx  =  R[edx]  <-  R[edx] + M[R[eax]]
