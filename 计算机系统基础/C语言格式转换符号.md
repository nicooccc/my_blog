## 1. 一个格式说明符的完整结构

```text
%  [标志][宽度][.精度][长度修饰符]转换字符
│     │      │     │         │          │
│     │      │     │         │          └─ 必填。d i u o x X f e g a c s p n %
│     │      │     │         └──────────── 可选。h hh l ll z j t L
│     │      │     └────────────────────── 可选。. 开头，表示精度
│     │      └──────────────────────────── 可选。十进制数字，最小字段宽度
│     └─────────────────────────────────── 可选。- + 空格 # 0
└───────────────────────────────────────── 格式说明符的起始标志（必填）
```

以 `%08X` 为例：
```text
%   0      8      X
│   │      │      └── 转换字符：无符号十六进制，字母大写
│   │      └───────── 最小字段宽度：至少 8 个字符
│   └──────────────── 标志 0：左边补 0 而不是补空格
└──────────────────── 起始标志
```

另外还有两个特殊形式：

| 形式 | 含义 | 示例 |
|---|---|---|
| `%*d` | 宽度由**参数**给出，不写死在格式串里 | `printf("%*d", 6, 42)` → `    42` |
| `%.*f` | 精度由**参数**给出 | `printf("%.*f", 2, 3.14159)` → `3.14` |
| `%%` | 输出一个百分号本身 | `printf("100%%")` → `100%` |

## 2. 转换字符总表

| 转换字符 | 参数类型 | 输出含义 | 实测示例 | 输出 |
|---|---|---|---|---|
| `%d` / `%i` | `int` | 有符号十进制 | `printf("%d", -42)` | `-42` |
| `%u` | `unsigned int` | 无符号十进制 | `printf("%u", 4294967295u)` | `4294967295` |
| `%o` | `unsigned int` | 无符号八进制（无前缀） | `printf("%o", 42)` | `52` |
| `%x` / `%X` | `unsigned int` | 无符号十六进制，小写 / 大写 | `printf("%x %X", 255, 255)` | `ff FF` |
| `%f` / `%F` | `double` | 定点小数，默认 6 位小数 | `printf("%f", 3.14159265)` | `3.141593` |
| `%e` / `%E` | `double` | 科学计数法 | `printf("%e", 31415.9265)` | `3.141593e+04` |
| `%g` / `%G` | `double` | 自动选 `%f` 或 `%e`，并**去掉尾部多余的 0** | `printf("%g", 31415.9265)` | `31415.9` |
| `%a` / `%A` | `double` | 十六进制浮点（C99） | `printf("%a", 1.0)` | `0x1p+0` |
| `%c` | `int`（实参是字符） | 单个字符 | `printf("%c %c", 'A', 97)` | `A a` |
| `%s` | `char *` | 字符串 | `printf("%.3s", "hello")` | `hel` |
| `%p` | `void *` | 指针地址（格式由实现决定） | `printf("%p", (void*)0x2BD7)` | `0000000000002bd7` |
| `%n` | `int *` | **不输出**，把已输出字符数写回参数 | 见下方说明 | — |
| `%%` | 无 | 输出 `%` | `printf("100%%")` | `100%` |

**`%i` 与 `%d` 在 `printf` 里完全等价**（都按十进制输出），区别只在 `scanf`（见第 8 节）。

**`%n` 说明**：它把**此前已经输出的字符个数**写进参数指向的变量里，本身不产生输出：

```c
int n;
printf("12345%n\n", &n);   /* 先输出 12345，再把 5 写进 n */
printf("%d\n", n);         /* 5 */
```

**`%g` 的取值规则**：指数小于 -4 或不小于精度时用 `%e`，否则用 `%f`，并且**删除小数部分末尾无意义的 0**（除非用了 `#`）。

```
%g   31415.9265   ->  31415.9
%g   0.000031415  ->  3.1415e-05
```

## 3. 标志（flags）

| 标志 | 作用 | 实测示例 | 输出 |
|---|---|---|---|
| `-` | 左对齐（默认右对齐） | `printf("[%-6d]", 42)` | `[42    ]` |
| `+` | 正数也显示 `+` | `printf("%+d %+d", 42, -42)` | `+42 -42` |
| `空格` | 正数前面补一个空格（与 `+` 互斥，`+` 优先） | `printf("[% d] [% d]", 42, -42)` | `[ 42] [-42]` |
| `#` | 用"替代形式"输出 | 见下方 | — |
| `0` | 用 `0` 补齐左边（只对右对齐有效） | `printf("%08d %08d", 42, -42)` | `00000042 -0000042` |

**`#` 的具体表现**：

| 组合 | 效果 | 实测示例 | 输出 |
|---|---|---|---|
| `%#o` | 八进制加前缀 `0` | `printf("%#o", 42)` | `052` |
| `%#x` / `%#X` | 十六进制加前缀 `0x` / `0X` | `printf("%#x %#X", 255, 255)` | `0xff 0XFF` |
| `%#.0f` | 强制保留小数点 | `printf("%.0f %#.0f", 3.0, 3.0)` | `3 3.` |
| `%#g` | 保留尾部无意义的 0 | `printf("%g %#g", 3.0, 3.0)` | `3 3.00000` |

**`-` 与 `0` 同时出现时 `0` 被忽略**（编译器会给出 `-Wformat` 警告）：

```c
printf("[%-08d]", 42);   /* 输出 [42      ]，不是 [42000000] */
```

## 4. 宽度与精度（width / precision）

### 4.1 宽度（width）：最小字段宽度，只补不截

```c
printf("[%6d]", 42);    /* [    42]   补空格到 6 位 */
printf("[%-6d]", 42);   /* [42    ]   左对齐 */
printf("%02X", 0x1234); /* 1234       数值本身就超过 2 位，照实输出，不截断 */
```

`%02X` 打印 `0x1234` 得到 `1234`（4 位），**这是最容易误解的一点**：宽度只是"至少几位"。

### 4.2 精度（precision）：不同类型含义不同

| 用于 | 含义 | 实测示例 | 输出 |
|---|---|---|---|
| 整数 `d i u o x X` | **最少位数**，不足左边补 `0` | `printf("%.5d %8.5d", 42, 42)` | `00042    00042` |
| 字符串 `s` | **最多输出几个字符**（截断） | `printf("%.3s", "hello")` | `hel` |
| 浮点 `f e` | **小数点后几位**（默认 6） | `printf("%.2f", 3.14159)` | `3.14` |
| 浮点 `.0` | 不输出小数点和小数位 | `printf("%.0f", 3.14159)` | `3` |

注意整数精度里"补 0"与 `0` 标志的区别：精度补的 `0` 在**符号之后、数字之前**，且**算进字段宽度**。

```c
printf("%8.5d", 42);   /*     00042   总宽 8：3 个空格 + 补出的 00042 */
printf("%08d", 42);    /* 00000042    0 标志与宽度配合 */
```

### 4.3 星号：运行时指定

```c
printf("%*d", 6, 42);        /*     42    宽度 = 6 */
printf("[%-*d]", 8, 42);     /* [42      ] */
printf("%.*f", 2, 3.14159);  /* 3.14      精度 = 2 */
```

## 5. 长度修饰符（length）

长度修饰符告诉 `printf`"参数实际是哪种长度"，**必须与实参类型匹配**。

| 修饰符 | 配合的实参类型 | 实测示例 | 输出 |
|---|---|---|---|
| `hh` | `signed char` / `unsigned char` | `printf("%hhd %hhu %hhX", (signed char)200, (unsigned char)200, (unsigned char)200)` | `-56 200 C8` |
| `h` | `short` / `unsigned short` | `printf("%hd %hu %hX", 40000, 60000, 65535)` | `-25536 60000 FFFF` |
| （无） | `int` / `unsigned int` | `printf("%d %u", -1, 1u)` | `-1 1` |
| `l` | `long` / `unsigned long` | `printf("%ld %lu %lx", 123456789L, 123456789UL, 123456789UL)` | `123456789 123456789 75bcd15` |
| `ll` | `long long` / `unsigned long long` | `printf("%lld %llu %llX", -9007199254740993LL, 18446744073709551615ULL, 18446744073709551615ULL)` | `-9007199254740993 18446744073709551615 FFFFFFFFFFFFFFFF` |
| `z` | `size_t`（`%zu`） | `printf("%zu", sizeof(long))` | `4`（**平台相关**：本机 `long` 为 4 字节；`%zu` 打印的是 `sizeof(long)` 这个 `size_t` 值，别把两者混为一谈） |
| `j` | `intmax_t`（`%jd`） | `printf("%jd", (intmax_t)-1)` | `-1` |
| `t` | `ptrdiff_t`（`%td`） | `printf("%td", (ptrdiff_t)-7)` | `-7` |
| `L` | `long double`（`%Lf`） | `printf("%Lf", 3.14159265358979L)` | `3.141593` |

实测输出汇总：

```text
hh : -56 | 200 | C8
h  : -25536 | 60000 | FFFF
l  : 123456789 | 123456789 | 75bcd15
ll : -9007199254740993 | 18446744073709551615 | FFFFFFFFFFFFFFFF
z  : 4
j  : -1
L  : 3.141593 | 3.1416
t  : -7
```

**`%hX` 打印 `FFFF` 而不是 `FFFFFFFF`**，正是因为长度修饰符 `h` 告诉 `printf`"这个参数按 16 位解释"。没有 `h` 时，`short` 实参先被**默认实参提升**成 `int`，`0xFFFF` 会提升成 `0xFFFFFFFF`，打印出 8 位数字。这一点是 PTA 那两道题的核心考点，见第 9 节。

## 6. 长度修饰符 × 转换字符 组合合法性

| 组合 | 常用写法 | 说明 |
|---|---|---|
| `%hhd %hhu %hhx` | ✅ | 8 位类型；也可用 `%d` + `& 0xFF` 代替 |
| `%hd %hu %hx` | ✅ | 16 位类型；也可用 `%d` + `& 0xFFFF` 代替 |
| `%ld %lu %lx` | ✅ | `long` |
| `%lld %llu %llx` | ✅ | `long long` |
| `%zu %zd` | ✅ | `size_t`（`%zd` 用于 `ssize_t`，POSIX 非标准 C，与 `z` 搭配时是**有符号**版本） |
| `%tu %td` | ✅ | `ptrdiff_t` 的无符号 / 有符号形式（`t` 也是 C99 新增） |
| `%jd %ju` | ✅ | `intmax_t` / `uintmax_t` |
| `%Lf %Le %Lg` | ✅ | `long double` |
| `%lf` | ⚠️ | 在 `printf` 里 `l` 对浮点**无效**（`%f` 本来就接受 `double`）；但在 **`scanf` 里 `%lf` 是必须的** |
| `%s` + `l`（`%ls`） | ✅ | 宽字符串 `wchar_t *`（Windows 上是 `wchar_t`） |
| `%x` + `l` + `float` | ❌ | 类型不匹配，未定义行为 |

## 7. 补零的实际含义：`%08X` 拆解

`%08X` = `%` + 标志`0` + 宽度`8` + 转换字符`X`：

```text
%08X  打印 (unsigned)0x2BD7
       └─> 00002BD7
           └──┬──┘
        6 个补的 0 + 2BD7，共 8 位
```

| 格式 | `(unsigned)0x2BD7` | 补零行为 |
|---|---|---|
| `%X` | `2BD7` | 不补齐 |
| `%8X` | `    2BD7` | 补**空格**到 8 位 |
| `%08X` | `00002BD7` | 补 **0** 到 8 位 |
| `%x` | `2bd7` | 小写字母 |
| `%#010x` | `0x00002bd7` | 带前缀，且 `0x` **也算进 10 位宽度**里 |
| `%#010X` | `0X00002BD7` | 同上，但前缀变成 `0X`、字母大写 |

### 宽度怎么定？按"类型位数 ÷ 4"

| 类型 | 位数 | 十六进制位数 | 格式 |
|---|---|---|---|
| `int` / `unsigned int` | 32 | 32 ÷ 4 = **8** | `%08X` |
| `short` / `unsigned short` | 16 | 16 ÷ 4 = **4** | `%04X` |
| `char` / `unsigned char` | 8 | 8 ÷ 4 = **2** | `%02X` |
| `long long` / `unsigned long long`（本机 64 位） | 64 | 64 ÷ 4 = **16** | `%016llX` |

## 8. `printf` 与 `scanf` 的区别（重点）

两者共用同一套转换字符，但**语义相反**、规则不同，考试和写代码都常混。

| 对比项 | `printf`（输出） | `scanf`（输入） |
|---|---|---|
| 参数传递 | 传**值** | 传**地址**（`&x`，字符串数组名除外） |
| 宽度 | 最小字段宽度，**补**齐 | **最多读取**几个字符 |
| 精度 `.n` | 有效（小数位 / 截断 / 补 0） | **不允许**，写了是未定义行为 |
| 标志 `+` `-` `#` `0` | 有效 | **不允许** |
| `%d` | 输出 int | 读入**十进制**整数 |
| `%i` | 同 `%d` | 按**前缀自动判断进制**：`0x` → 十六进制，`0` → 八进制，否则十进制 |
| `%x` / `%X` | 输出无符号十六进制 | 读入十六进制（有无 `0x` 前缀都可以） |
| `%f` | 输出 double | 读入 **float**（`float *`） |
| `%lf` | ⚠️ 无意义 | 读入 **double**（`double *`）——读 double **必须**写 `%lf` |
| `%Lf` | long double | long double（`long double *`） |
| `%c` | 输出字符 | 读入字符（**不跳过前导空白**，包括 `\n`） |
| `%s` | 输出字符串 | 读入不含空白的单词（**自动跳过前导空白**，并补 `\0`） |
| `%p` | 输出指针值 | 读入指针（`void **`，格式实现相关，很少用） |
| `%n` | 写回已输出字符数 | 写回已读入字符数 |
| `%u` | 无符号十进制 | 读入十进制 `unsigned int`（**不接受负号**） |

**几个必记结论**：

```c
int    n;   double d;   float s;   char c;   char buf[64];

scanf("%d",  &n);       /* ✅ int 用 %d */
scanf("%lf", &d);       /* ✅ double 必须用 %lf（用 %f 是错的） */
scanf("%f",  &s);       /* ✅ float 用 %f */
scanf("%c",  &c);       /* ⚠️ 会读到残留的换行符；想跳过空白写成 " %c" */
scanf("%s",   buf);     /* ✅ 数组名本身就是地址，不加 & */
scanf("%x",  &n);       /* ✅ 读十六进制，输入写 0x12345678 或 12345678 都行 */

printf("%lf\n", d);     /* ⚠️ 合法但 l 无效，等价于 %f，不建议这么写 */
```

**`%i` 的自动进制**（`printf` 里没有这个能力，只有 `scanf` 有）：

```c
scanf("%i", &n);
/* 输入 0x1F  -> n = 31      （十六进制）
   输入 017   -> n = 15      （八进制）
   输入 31    -> n = 31      （十进制） */
```

## 9. 实战案例：同一个数的五种写法

`x = -1` 在各类型下"存储值"看起来一样（都是全 1），但**打印出来的数字取决于你用哪个转换字符**：

```c
int x = -1;
printf("%%d=%d  %%u=%u  %%X=%X  %%08X=%08X  %%o=%o\n",
       x, (unsigned)x, (unsigned)x, (unsigned)x, (unsigned)x);
```

实测输出：

```text
x=-1 : %d=-1  %u=4294967295  %X=FFFFFFFF  %08X=FFFFFFFF  %o=37777777777
```

**整型提升**（`printf` 的可变参数机制决定，务必记牢）：

```c
short s = -1;
printf("(unsigned)s=%X   (unsigned)s&0xFFFF=%X   %%04X=%04X\n",
       (unsigned)s, (unsigned)s & 0xFFFFu, (unsigned)s & 0xFFFFu);
```

实测输出：

```text
short -1 提升: (unsigned)s=FFFFFFFF   (unsigned)s&0xFFFF=FFFF   %04X=FFFF
```

- `short` / `char` 传给 `printf` 时先**提升为 `int`**；负数是**符号扩展**，`0xFFFF` → `0xFFFFFFFF`；
- 所以想打印"真实的 16 位存储值"，必须 `& 0xFFFF`；打印"真实的 8 位存储值"，必须 `& 0xFF`；
- 或用长度修饰符 `%hX` / `%hhX` 达到同样效果。

## 10. 高频坑清单

1. **`%X` 传了负数**：输出补码位模式（`-1` → `FFFFFFFF`），严格说是类型不匹配的未定义行为。规范做法先转 `(unsigned)`。
2. **`%08X` 只能补零，不能截断**：`%02X` 打印 `0x1234` 得到 `1234`。
3. **`short`/`char` 忘记 `&0xFFFF`/`&0xFF`**：得到 8 位数字（详见第 9 节）。
4. **`printf` 里写 `%lf`**：合法但 `l` 无效；只有 `scanf` 读 `double` 才必须 `%lf`。
5. **`%d` 配 `long`**：Linux x86-64 上 `long` 是 8 字节而 `int` 是 4 字节，`%d` 打印 `long` 属未定义行为，应写 `%ld`；本机 `long` 恰好是 4 字节，所以 `%d` "看起来能用"——**这种代码跨平台必炸**。
6. **`%u` 配负数**：`printf("%u", -1)` 会输出 `4294967295`，但类型不匹配；应写 `printf("%u", (unsigned)-1)`。
7. **`%s` 精度用来截断**：`%.3s` 输出前 3 个字符；而 `%3s` 是补宽到 3 位，两者不同。
8. **`-` 与 `0` 同时用**：`0` 被忽略。
9. **`%g` 会去掉尾部的 0**：需要固定宽度小数用 `%f`；需要保留尾部 0 用 `%#g`。
10. **`#` 配 `X` 会得到 `0X` 不是 `0x`**：`printf("%#010X", 0x2BD7)` 输出 `0X00002BD7`，想要小写前缀要用 `%#010x`。
11. **`%n` 有安全风险**：格式化字符串漏洞常利用它，写代码时除非必要别用。
12. **平台相关项**：`char` 是否有符号、`long` 宽度、`size_t` 宽度、`%p` 的输出格式，跨平台时必须用 `<inttypes.h>` 的 `PRId64` 等宏。本机实测为 LP64 之外的 `long = 4` 模型（`int/long = 4`，`long long/size_t/指针 = 8`），而 Linux x86-64 是 `long = 8`，**同一份代码换平台就可能错**：

```c
#include <inttypes.h>
int64_t v = -1;
printf("%" PRId64 "\n", v);   /* 可移植写法 */

size_t n = 123;
printf("%zu\n", n);           /* size_t 用 %zu，不要用 %d / %ld */
```

## 12. 速查卡

```text
转换字符（printf 传值，scanf 传地址）
  d  有符号十进制 int            i  scanf 专用：自动判进制
  u  无符号十进制                o  八进制无前缀
  x  十六进制小写                X  十六进制大写
  f  定点小数(6位)               e  科学计数法      g  自动并去尾 0
  a  十六进制浮点                c  字符            s  字符串
  p  指针                        n  回写字符数      %% 百分号

标志
  -  左对齐        +  强制显示正号      空格  正数前留空格
  #  替代形式(0/0x/保留小数点)            0  左边补 0

宽度.精度
  宽度  = 最小字段宽度（只补不截）
  精度  = 整数最少位数 / 字符串最多字符数 / 浮点小数位

长度修饰符
  hh 8位   h 16位   (无) 32位   l long   ll 64位
  z size_t   j intmax_t   t ptrdiff_t   L long double

按类型位数 ÷ 4 定十六进制宽度
   8 位 -> %02X     16 位 -> %04X     32 位 -> %08X     64 位 -> %016llX

窄类型打印前先消掉提升带来的高位
   short/unsigned short  ->  & 0xFFFF   或  %hX
   char /unsigned char   ->  & 0xFF     或  %hhX
```
